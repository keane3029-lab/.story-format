# Creator's Note

Hi, I'm Keane, the person behind .STORY.

I am a student and indie developer based in Cagayan de Oro, Philippines. I do most of my building from my phone, so I care a lot about tools that are small, plain, and easy to use without a big setup. That is the idea behind this format.

## Why I made it

There are a lot of file formats out there for story game developers to choose from, and picking one can be a project on its own. Some are powerful but heavy, and some take a while to learn before you can write a single line. I wanted one simple option that stays out of the way: write your days, your dialogue, and your narration in plain text, and let a tiny parser handle the rest.

## What I want it to be

A format that anyone can write by hand and anything can read. No lock-in, no special editor, no heavy tooling. If you can type text, you can write a .STORY file.

## Where it is going

I plan to publish the parser to npm so anyone can install it with one command. Beyond that, I want to see what other people build with it, like story players, visual novel tools, and games.

## Contributing

Ideas, bug reports, and pull requests are welcome. If you find a line the parser handles badly, open an issue and include the line and the warning it gave you.

## Support the project

The best way to support .STORY is to spread the word. Star the repo, share it with other story game devs, and tell a friend who writes dialogue-heavy games or visual novels. The more people who know it exists, the more it grows, and the more it can be improved by people who actually use it.

## Thanks

Thank you for checking out .STORY. If you make something with it, I would love to see it.

Keane
